transition — плавна зміна

Анімує зміну CSS-властивостей між двома станами (напр. при :hover).

.button {
  background: blue;

  /* властивість | тривалість | функція | затримка */
  transition: background 0.3s ease 0s;

  /* Кілька властивостей */
  transition: background 0.3s ease, transform 0.2s ease;

  /* Всі властивості (уникати — повільніше) */
  transition: all 0.3s ease;
}

.button:hover {
  background: darkblue;
  transform: scale(1.05);
}

/* transition: ЗАВЖДИ на початковому стані, НЕ на :hover */

transform — трансформації

Не впливає на потік документа — сусідні елементи не зміщуються. Ідеальний для анімацій.

.el {
  /* Переміщення */
  transform: translateX(50px);      /* вправо */
  transform: translateY(-20px);     /* вгору */
  transform: translate(50px, -20px); /* X і Y разом */

  /* Масштаб */
  transform: scale(1.2);   /* 120% від оригінального розміру */
  transform: scaleX(2);   /* тільки по горизонталі */

  /* Поворот */
  transform: rotate(45deg);

  /* Кілька трансформацій (порядок важливий!) */
  transform: translateX(20px) rotate(45deg) scale(1.1);
}

@keyframes + animation

Для складних анімацій з кількома кроками.

/* 1. Описуємо кадри */
@keyframes fadeIn {
  from {
    opacity: 0;
    transform: translateY(-10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

@keyframes pulse {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.1); }
  100% { transform: scale(1); }
}

/* 2. Застосовуємо */
.card {
  /* name | duration | timing | delay | count | direction | fill */
  animation: fadeIn 0.5s ease 0s 1 normal forwards;
}

.loader {
  animation: pulse 1.5s ease-in-out infinite;
}
ВластивістьЗначення
animation-nameназва @keyframes
animation-duration0.5s, 1200ms
animation-timing-functionease, linear, ease-in-out
animation-delay0s, 0.3s (затримка старту)
animation-iteration-count1, 3, infinite
animation-directionnormal, reverse, alternate
animation-fill-modenone, forwards (зберегти кінцевий стан), backwards
animation-play-staterunning, paused

Spinner завантаження

@keyframes spin {
  to { transform: rotate(360deg); }
}

.spinner {
  width: 32px; height: 32px;
  border: 3px solid #eee;
  border-top-color: blue; /* тільки верхня частина кольорова */
  border-radius: 50%;      /* перетворює на коло */
  animation: spin 0.8s linear infinite;
}

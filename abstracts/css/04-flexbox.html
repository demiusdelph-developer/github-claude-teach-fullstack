Flexbox

Одновимірне розміщення елементів — в рядок або стовпець. Ідеальний для навбарів, карток і будь-якого лінійного лейауту.

Вмикаємо flex

Одна властивість перетворює контейнер на flex-контейнер. Всі прямі дочірні стають flex-елементами.

.container {
  display: flex;  /* вмикаємо flexbox */
}

Властивості елемента (flex-item)

Застосовуються до дочірніх елементів, а не до контейнера.

flex — скорочення (grow shrink basis)

.item {
  flex: 1;          /* = flex: 1 1 0 — росте, стискається, база 0 */
  flex: 0 0 200px;  /* фіксована ширина 200px, не росте і не стискається */
  flex: 1 1 280px;  /* мінімум 280px, може рости і стискатись */

  /* Окремо: */
  flex-grow: 1;    /* як росте відносно інших (0 = не росте) */
  flex-shrink: 1;  /* як стискається (0 = не стискається) */
  flex-basis: auto; /* базовий розмір до розподілу простору */
}

flex-grow: різні значення

flex: 1

зелений (flex:2) займає вдвічі більше вільного місця

order — порядок відображення

.item-3 { order: -1; } /* першим */
.item-1 { order: 0; }  /* за замовч. */
.item-2 { order: 1; }  /* останнім */

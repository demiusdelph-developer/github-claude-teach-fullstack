Селектори

Визначають до яких елементів застосовуються стилі.

Тег / клас / ID

/* тег — всі елементи цього типу */
p { color: black; }

/* клас — будь-який елемент з class="..." */
.card { background: white; }

/* ID — унікальний елемент */
#header { height: 80px; }

Нащадок / дочірній / сусід

/* нащадок — пробіл між ними */
.card p { font-size: 14px; }

/* прямий дочірній — > */
.nav > li { display: inline-block; }

/* сусідній — + */
h2 + p { margin-top: 0; }

/* всі сусідні — ~ */
h2 ~ p { color: gray; }

Псевдокласи — стан елемента

a:hover           { color: blue; }
button:active     { opacity: 0.8; }
input:focus       { border-color: blue; }

li:first-child    { font-weight: bold; }
li:last-child     { margin-bottom: 0; }
li:nth-child(2)   { color: red; }
li:nth-child(odd) { background: #f0f0f0; }

a:visited         { color: purple; }
p:not(.special)  { color: gray; }

Псевдоелементи — частина елемента

p::first-line  { font-size: 18px; }
p::first-letter{ font-size: 2em; }

.card::before {
  content: "★";
  color: gold;
}

.card::after {
  content: "";
  display: block;
  clear: both;
}

::selection { background: #3b82f6; }

Специфічність

Коли кілька правил конфліктують — перемагає те, що має вищу специфічність.

Вага правил — від найнижчої до найвищої

tag — p
1 один тег = 1 очко
.class, :hover — .card
10 клас або псевдоклас = 10
#id — #header
100 ID = 100 очок
style="" (inline)
1000 інлайн стилі = 1000
!important
∞ перевизначає все — уникати! 
/* Конфлікт — яке правило переможе? */
p          { color: black; }   /* вага: 1 */
.text      { color: blue; }    /* вага: 10 — перемагає */
#main p    { color: green; }   /* вага: 101 — перемагає */
.card.dark { color: white; }   /* вага: 20 */

Кольори

Чотири способи задати колір — всі рівноцінні, але HEX і HSL найзручніші.

.element {
  /* Назва кольору */
  color: red;
  color: transparent;

  /* HEX — #rrggbb */
  color: #ff0000;   /* повний */
  color: #f00;      /* скорочений (коли пари однакові) */
  color: #ff000080; /* з прозорістю (80 = ~50%) */

  /* RGB / RGBA */
  color: rgb(255, 0, 0);
  color: rgba(255, 0, 0, 0.5);   /* 0 = прозорий, 1 = непрозорий */

  /* HSL — відтінок (0-360), насиченість, яскравість */
  color: hsl(0, 100%, 50%);     /* червоний */
  color: hsl(120, 100%, 50%);   /* зелений */
  color: hsla(0, 100%, 50%, 0.5); /* з прозорістю */
}

Одиниці виміру

Абсолютні (px) і відносні (%, rem, em, vw) — кожна має своє призначення.

Абсолютні

.box {
  width: 300px;  /* пікселі — фіксовано */
}
ОдиницяПризначення
pxПікселі — для чітких розмірів
ptПункти — для друку

Відносні

.box {
  width: 50%;    /* від ширини батька */
  font-size: 1rem; /* від html (16px зазвич.) */
  font-size: 1.2em; /* від батьківського font-size */
  width: 100vw;  /* 100% ширини вікна */
  height: 100vh; /* 100% висоти вікна */
}

Коли що використовувати

ОдиницяКолиПриклад
pxЧіткі межі, border, box-shadowborder: 1px solid
remТекст, відступи — масштабується з налаштуваннями браузераfont-size: 1rem
emВідступи відносно поточного шрифтуpadding: 0.5em 1em
%Ширина відносно батькаwidth: 50%
vw / vhРозміри відносно вікнаheight: 100vh
frЧастки в Gridgrid-template-columns: 1fr 2fr

Скидання стилів браузера

Браузер додає свої стилі — їх потрібно скинути на початку кожного проекту.

/* Додавай завжди першим рядком у style.css */
*, *::before, *::after {
  box-sizing: border-box; /* width включає padding і border */
  margin: 0;
  padding: 0;
}

body {
  font-family: system-ui, sans-serif;
  line-height: 1.5;
}

img {
  max-width: 100%;   /* зображення не виходять за межі контейнера */
  display: block;
}

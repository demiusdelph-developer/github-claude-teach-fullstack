Font Awesome — бібліотека іконок

Підключається одним рядком у <head>. Понад 2000 безкоштовних іконок.

Підключення через CDN

<!-- Додай у <head> -->
<link rel="stylesheet"
      href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css" />
CDN означає Content Delivery Network — файл завантажується з серверів Cloudflare, а не з твого проекту. Швидко, але потрібен інтернет.

Стилізація через CSS

/* Розмір — через font-size */
i { font-size: 24px; }

/* Колір — через color */

.icon-danger  { color: #ff7b72; }

/* Розміри від FA: fa-xs fa-sm fa-lg fa-xl fa-2x..fa-10x */

Кнопки з іконками

Inline SVG — максимум контролю

SVG прямо в HTML — можна стилізувати через CSS: колір, розмір, анімацію. Підходить для власних іконок і лого.

Базова структура SVG

<svg
  xmlns="http://www.w3.org/2000/svg"
  width="24"
  height="24"
  viewBox="0 0 24 24"      <!-- координатна система -->
  fill="none"              <!-- колір заливки: none або колір -->
  stroke="currentColor"  <!-- stroke береться з CSS color -->
  stroke-width="2"
>
  <!-- Фігури: circle, rect, path, line, polyline -->
  <circle cx="12" cy="12" r="10"/>
  <line x1="12" y1="8" x2="12" y2="12"/>
</svg>
currentColor — спеціальне ключове слово: SVG успадкує CSS color батьківського елемента. Зміни color — зміниться і іконка.

Стилізація inline SVG через CSS

.icon {
  width: 24px;
  height: 24px;
  color: #388bfd;         /* якщо SVG використовує currentColor */
  transition: color 0.2s ease;
}

.icon:hover {
  color: #79c0ff;
}

/* Або напряму через fill/stroke: */
.icon path {
  fill: #388bfd;
}
.icon circle {
  stroke: #388bfd;
}

currentColor — іконки успадковують color батька

SVG як файл — <img> і <object>

Зовнішній SVG-файл — найпростіше підключення, але стилізація CSS обмежена.

<img> — найпростіше

<img
  src="icons/logo.svg"
  alt="Логотип"
  width="32"
  height="32"
/>

⚠ Не можна змінити колір через CSS — SVG рендериться як зображення.

CSS для <img src="*.svg">

img.icon {
  width: 32px;
  height: 32px;
  opacity: 0.8;

  /* Можна через filter() змінити колір! */
  filter: invert(1);      /* чорний → білий */
  filter: brightness(0); /* будь-який → чорний */
}

object-fit — вписати зображення в контейнер

Властивість для <img> та <video> — як заповнює заданий розмір.

img {
  width: 200px;
  height: 200px;
  object-fit: cover;    /* заповнює весь прямокутник, обрізає зайве */
  object-fit: contain; /* вписує повністю, можуть бути поля */
  object-fit: fill;    /* розтягує до розмірів (спотворює) */
  object-fit: none;    /* оригінальний розмір, обрізається */

  /* Фокус — яка частина видима при cover */
  object-position: center;  /* за замовч. */
  object-position: top;
  object-position: 50% 20%; /* x y */
}

Одне зображення — різні object-fit (симуляція градієнтами)

ЗОБРАЖЕННЯ

fill (розтягує)

ЗОБРАЖЕННЯ

contain (поля)

ЗОБРАЖЕННЯ

cover (обрізає)

aspect-ratio — зберегти пропорції

.avatar {
  width: 100%;
  aspect-ratio: 1 / 1;   /* квадрат — ширина = висота */
  object-fit: cover;
  border-radius: 50%;    /* коло */
}

.banner {
  width: 100%;
  aspect-ratio: 16 / 9;  /* відео-формат */
  object-fit: cover;
}
aspect-ratio — без нього потрібно хакати через padding-top: 56.25% (старий трюк). Тепер не потрібен.

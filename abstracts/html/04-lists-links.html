Списки і посилання

ul, ol, dl — три типи списків. <a> — єдиний тег для посилань з багатьма варіантами href.

Три типи списків

ul — невпорядкований (булети)

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
  • HTML
  • CSS
  • JavaScript

ol — впорядкований (нумерація)

<ol>
  <li>Перший крок</li>
  <li>Другий крок</li>
  <li>Третій крок</li>
</ol>
  1. Перший крок
  2. Другий крок
  3. Третій крок

dl — список означень

<dl>
  <dt>HTML</dt>
  <dd>Мова розмітки</dd>

  <dt>CSS</dt>
  <dd>Таблиці стилів</dd>
</dl>
HTML
Мова розмітки
CSS
Таблиці стилів

Вкладені списки і атрибути ol

<!-- Вкладений список -->
<ul>
  <li>Frontend
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
</ul>

<!-- Атрибути ol -->
<ol start="5">       <!-- нумерація з 5 -->
<ol reversed>        <!-- зворотня: 3, 2, 1 -->
<ol type="A">        <!-- A, B, C... (або a, I, i) -->

Посилання <a>

Один тег, але href може бути дуже різним.

<!-- Зовнішнє посилання -->
<a href="https://google.com">Google</a>

<!-- В новій вкладці — ЗАВЖДИ з rel="noopener noreferrer" -->
<a href="https://google.com"
   target="_blank"
   rel="noopener noreferrer">Google (нова вкладка)</a>

<!-- Внутрішня сторінка -->
<a href="about.html">Про нас</a>
<a href="../index.html">На рівень вище</a>

<!-- Якір — перехід до елемента з id на тій самій сторінці -->
<a href="#contacts">До контактів</a>
<section id="contacts">...</section>

<!-- Email -->
<a href="mailto:email@example.com">Написати</a>

<!-- Телефон -->
<a href="tel:+380501234567">+38 050 123 45 67</a>

<!-- Завантаження файлу -->
<a href="resume.pdf" download>Завантажити резюме</a>
<a href="resume.pdf" download="Dmytro-CV.pdf">Завантажити</a>
⚠ rel="noopener noreferrer" — обов'язково при target="_blank". Без нього відкрита сторінка може отримати доступ до твоєї через window.opener — вразливість безпеки.

Посилання vs Кнопка

ВикористовуйКоли
<a href="...">Навігація — переходиш на іншу сторінку або якір
<button>Дія — відправляєш форму, відкриваєш модалку, запускаєш JS
Не використовуй <a> без href для кнопок — це ламає доступність. Не використовуй <button> для навігації.

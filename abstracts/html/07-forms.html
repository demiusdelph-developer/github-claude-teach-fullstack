Форми

Форми — головний спосіб отримати дані від користувача. form, input, label, select, textarea, button.

← 06 — Таблиці ← До всіх конспектів

Базова структура форми

<form action="/submit" method="POST">
  <!-- action — куди надсилати (URL) -->
  <!-- method — GET (в URL) або POST (в тілі) -->

  <label for="name">Ім'я:</label>
  <input
    type="text"
    id="name"
    name="name"               <!-- ключ при надсиланні -->
    placeholder="Введіть ім'я"
    required
  />

  <button type="submit">Надіслати</button>
</form>

<label> — обов'язковий підпис

<!-- Спосіб 1: for + id (рекомендований) -->
<label for="email">Email:</label>
<input type="email" id="email" name="email" />
<!-- Клік на label = фокус на input -->

<!-- Спосіб 2: обгортання -->
<label>
  Email:
  <input type="email" name="email" />
</label>

Всі типи <input>

<!-- Текстові -->
<input type="text"     />  однорядковий текст
<input type="password" />  символи приховані
<input type="email"    />  з валідацією формату
<input type="url"      />  URL з валідацією
<input type="tel"      />  телефон (мобільна клавіатура)
<input type="search"   />  пошук (з кнопкою очистки)

<!-- Числові -->
<input type="number" min="0" max="100" step="5" />
<input type="range"  min="0" max="100" value="50" />  повзунок

<!-- Дата і час -->
<input type="date"           />
<input type="time"           />
<input type="datetime-local" />

<!-- Вибір -->
<input type="checkbox" />            декілька можна обрати
<input type="radio" name="group" />  одна з групи
<input type="color"    />            вибір кольору
<input type="file"     />            завантаження файлу

<!-- Приховане (для токенів, id) -->
<input type="hidden" name="token" value="abc123" />
Живі приклади

Інші елементи форми

<!-- Багаторядковий текст -->
<textarea name="message" rows="5" placeholder="Текст..."></textarea>

<!-- Випадаючий список -->
<select name="city">
  <option value="">-- Обери --</option>
  <option value="kyiv">Київ</option>
  <option value="lviv" selected>Львів</option>
</select>

<!-- Кнопки -->
<button type="submit">Надіслати форму</button>
<button type="reset">Скинути</button>
<button type="button">Просто кнопка (для JS)</button>

<!-- Групування через fieldset -->
<fieldset>
  <legend>Особисті дані</legend>
  <input type="text" name="fname" />
</fieldset>

Важливі атрибути input

АтрибутПризначення
nameКлюч при надсиланні форми — обов'язковий!
idЗв'язок з <label for="id">
requiredПоле обов'язкове, форма не надіслиться без нього
placeholderПідказка всередині поля (зникає при введенні)
valueЗначення за замовчуванням
disabledПоле неактивне, значення не надсилається
readonlyТільки читання (але значення надсилається)
autofocusФокус на цьому полі при завантаженні сторінки
min / maxМінімум/максимум для числових і дат
minlength / maxlengthМінімум/максимум символів
patternРегулярний вираз для валідації (напр. тільки цифри)
multipleДекілька значень (для file і email)
autocomplete"off" — вимкнути автозаповнення

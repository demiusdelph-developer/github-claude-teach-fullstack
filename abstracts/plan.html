01

Фундамент

Місяці 1–3  ·  Зараз

🔄 В процесі

Мета: впевнено писати HTML, CSS, базовий JavaScript, вміти користуватись Git.

✅ HTML5 — виконано 🔄 CSS3 — в процесі ⏳ JavaScript ⏳ Git + GitHub
ТемаЩо опанувати
HTML5 ✅Семантична розмітка, форми, атрибути доступності
CSS3 🔄Flexbox, Grid, медіа-запити, анімації, змінні, іконки, шрифти
JavaScript ⏳Типи, функції, масиви, об'єкти, DOM, події, fetch
Git + GitHub ⏳commit, push, pull, гілки, pull request
Результат: робочий landing page + форма зворотного зв'язку, опублікований на GitHub
02

JavaScript в глибину

Місяці 3–5

⏳ Заплановано

Мета: зрозуміти мову на рівні, достатньому для React і Node.

ТемаЩо опанувати
ES6+let/const, arrow functions, деструктуризація, spread, модулі
АсинхронністьCallbacks → Promises → async/await
ООПКласи, прототипи, this
АлгоритмиБазові структури даних, сортування, рекурсія
Результат: SPA-додаток (todo або погода) з API запитами, без фреймворку
03

Frontend з React

Місяці 5–8

⏳ Заплановано

Мета: будувати сучасні UI на рівні джуна.

ТемаЩо опанувати
ReactJSX, компоненти, props, state, хуки (useState, useEffect, useContext)
TypeScriptТипи, інтерфейси, generics — достатньо для React
React RouterНавігація, вкладені маршрути
СтанuseReducer, Zustand або Redux Toolkit
СтиліTailwind CSS (пріоритет) або CSS Modules
Результат: React-застосунок з авторизацією, маршрутизацією, TypeScript — у портфоліо

ТемаЩо опанувати

05

Full Stack інтеграція

Місяці 11–13

⏳ Заплановано

Мета: зібрати все разом, задеплоїти реальний проект.

ТемаЩо опанувати

06

Пошук роботи

Місяці 13–14

⏳ Заплановано
→ Оформлення GitHub: README, опис проектів, скріншоти
→ CV і LinkedIn для українського / міжнародного ринку
→ Підготовка до технічного інтерв'ю — LeetCode легкий рівень (30–40 задач)
→ Mock-інтерв'ю
Результат: офер на першу роботу джуна 🎯

Як навчатись ефективно

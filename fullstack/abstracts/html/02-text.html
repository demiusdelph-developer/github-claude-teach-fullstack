Заголовки h1–h6

Ієрархія заголовків важлива для SEO і доступності. Один h1 на сторінку!

<h1>Найголовніший заголовок (один на сторінці!)</h1>
<h2>Розділ</h2>
<h3>Підрозділ</h3>
<h4>Підпідрозділ</h4>
<h5>Рідко використовується</h5>
<h6>Найменший заголовок</h6>
Браузер відображає так:

h1 — Заголовок сторінки

h2 — Розділ

h3 — Підрозділ

h4 — Підпідрозділ

h5 — Малий заголовок
h6 — Найменший
Правила ієрархії: після h2 йде h3, не h5. Пропускати рівні — помилка. Використовуй h1 один раз. Заголовки — для структури, не для розміру шрифту (розмір задавай CSS).

Параграф і переноси

<p>Це параграф. Браузер автоматично додає відступи.</p>

<!-- Перенос рядка всередині тексту (рідко потрібен) -->
<p>Перший рядок<br />Другий рядок</p>

<!-- Горизонтальна лінія-розділювач -->
<hr />

Семантичне форматування

Несуть змістове значення — читалки екрану реагують на них по-різному.

<strong>Важливий текст</strong>        <!-- жирний + "важливо" для читалки -->
<em>Виділений текст</em>              <!-- курсив + "наголос" -->
<mark>Підсвічений текст</mark>        <!-- жовте виділення -->
<del>Видалений текст</del>            <!-- перекреслення -->
<ins>Доданий текст</ins>              <!-- підкреслення -->
<small>Дрібний текст</small>          <!-- авторські права, примітки -->
<abbr title="HyperText Markup Language">HTML</abbr>  <!-- підказка при наведенні -->
<code>console.log('hi')</code>          <!-- рядок коду -->
<kbd>Ctrl + C</kbd>                    <!-- клавіші -->
<sub>нижній індекс</sub>              <!-- H₂O -->
<sup>верхній індекс</sup>            <!-- x² -->
<time datetime="2024-01-15">15 січня 2024</time>  <!-- для машин -->
Як виглядає:

strong · em (курсив) · mark · del · ins · small · code · Ctrl+C · H2O · x2

Лише візуальні — краще уникати

<b>Жирний</b>          <!-- те саме що strong але без "важливості" -->
<i>Курсив</i>           <!-- те саме що em але без "наголосу" -->
<u>Підкреслений</u>    <!-- користувачі плутають з посиланням -->

Цитати і код

<blockquote>

<blockquote cite="https://example.com">
  <p>Текст цитати...</p>
  <footer>— Автор</footer>
</blockquote>

<!-- Коротка цитата в тексті -->
<q>Коротка цитата</q>
<!-- Браузер додає лапки сам -->

<pre> + <code>

<!-- Зберігає пробіли і переноси -->
<pre><code>
function hello() {
  console.log("Hi");
}
</code></pre>

<!-- pre без code — для ASCII-арту,
     форматованого тексту -->

HTML-сутності (entities)

Спеціальні символи які не можна вставити напряму або які мають особливе значення в HTML.

СимволКодКоли
<&lt;Знак менше в тексті (інакше браузер думає що це тег)
>&gt;Знак більше в тексті
&&amp;Амперсанд у тексті
 &nbsp;Нерозривний пробіл (не переноситься)
©&copy;Копірайт
→&rarr;Стрілка вправо
—&mdash;Довге тире (em dash)
✓&#10003;Галочка

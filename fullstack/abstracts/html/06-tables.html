Таблиці

Таблиці — для табличних даних. thead, tbody, tfoot, colspan, rowspan.

← 05 — Зображення 07 — Форми →

Повна структура таблиці

<table>
  <caption>Список розробників</caption>   <!-- заголовок таблиці -->

  <thead>                                     <!-- Голова -->
    <tr>                                       <!-- рядок (table row) -->
      <th scope="col">Ім'я</th>              <!-- заголовок стовпця -->
      <th scope="col">Вік</th>
      <th scope="col">Місто</th>
    </tr>
  </thead>

  <tbody>                                     <!-- Тіло -->
    <tr>
      <td>Іван</td>                            <!-- комірка даних -->
      <td>25</td>
      <td>Київ</td>
    </tr>
    <tr>
      <td>Марія</td>
      <td>30</td>
      <td>Львів</td>
    </tr>
  </tbody>

  <tfoot>                                     <!-- Підвал -->
    <tr>
      <td colspan="3">Всього: 2 розробники</td>
    </tr>
  </tfoot>
</table>

Браузер відображає так:

Список розробників
Ім'яВікМісто
Іван25Київ
Марія30Львів
Всього: 2 розробники

colspan і rowspan — об'єднання комірок

colspan — по горизонталі

<td colspan="2">Займає 2 стовпці</td>
<td colspan="3">Займає 3 стовпці</td>
colspan="2" C
ABC

rowspan — по вертикалі

<td rowspan="2">Займає 2 рядки</td>
<!-- наступний рядок: ця комірка не повторюється -->
rowspan=2 B1 C1
B2 C2

scope — доступність таблиць

<!-- scope допомагає скрінрідерам -->
<th scope="col">Заголовок стовпця</th>
<th scope="row">Заголовок рядка</th>
<th scope="colgroup">Для групи стовпців</th>
Таблиці — тільки для табличних даних! Не використовуй table для макету сторінки. Для верстки є Flexbox і Grid.

Семантичні елементи

Семантичні теги описують роль вмісту. Пошукові системи і читалки екрану використовують їх для розуміння структури.

Чому семантика важлива

✗ Без семантики

<div class="header">
  <div class="nav">...</div>
</div>
<div class="main">
  <div class="article">...</div>
</div>
<div class="footer">...</div>

✓ З семантикою

<header>
  <nav>...</nav>
</header>
<main>
  <article>...</article>
</main>
<footer>...</footer>
Семантика = краще SEO + доступність для людей зі скрінрідерами + зрозуміліший код для команди.

Типова структура сторінки

<header> — шапка: лого, назва, навігація
<nav> — навігація
<aside>
бічна панель
<main> — основний вміст (один на сторінку)
<article> — стаття або пост
<section> — секція з заголовком
<footer> — підвал: копірайт, контакти

Всі семантичні теги

<header>
  <!-- Шапка сторінки або секції: лого, назва, навігація -->
  <!-- На сторінці може бути декілька (один для page, ще для article) -->
</header>

<nav>
  <!-- Блок навігаційних посилань -->
  <!-- Тільки для ГОЛОВНИХ навігаційних блоків -->
</nav>

<main>
  <!-- Основний унікальний вміст. ОДИН НА СТОРІНКУ. -->

  <article>
    <!-- Самодостатній контент: стаття, пост, коментар, картка -->
    <!-- Може існувати окремо від контексту -->
  </article>

  <section>
    <!-- Тематична секція з заголовком -->
    <h2>Назва секції (обов'язково!)</h2>
  </section>

</main>

<aside>
  <!-- Вміст пов'язаний але не головний: бічна панель, реклама, теги -->
</aside>

<footer>
  <!-- Підвал: копірайт, контакти, посилання -->
</footer>

<figure>
  <!-- Самодостатній медіа-блок -->
  <img src="chart.png" alt="Графік" />
  <figcaption>Підпис до зображення</figcaption>
</figure>

<details>
  <!-- Розгортуваний блок (акордеон без JS) -->
  <summary>Клікни щоб розкрити</summary>
  <p>Прихований текст</p>
</details>

article vs section — коли що

<article>

Самодостатній контент — може існувати окремо від сторінки. Питай себе: "якщо вирвати цей блок і показати окремо — він матиме сенс?"

✓ Стаття блогу
✓ Коментар
✓ Картка продукту
✓ Пост у соцмережі

<section>

Тематична частина контента з заголовком. Групує пов'язаний вміст. Завжди повинна мати h2-h6 всередині.

✓ Секція "Про нас"
✓ Секція "Наші послуги"
✓ Глава в статті
✗ Просто контейнер → використовуй div

Зображення <img>

<!-- Базове зображення -->
<img src="photo.jpg" alt="Опис зображення" />

<!-- alt обов'язковий завжди! -->
<!-- Для декоративних зображень alt залишати порожнім -->
<img src="divider.png" alt="" />

<!-- З розмірами (покращує CLS — Cumulative Layout Shift) -->
<img src="photo.jpg" alt="Фото" width="800" height="600" />

<!-- Lazy loading — завантажує тільки коли видно -->
<img src="photo.jpg" alt="Фото" loading="lazy" />
alt обов'язковий: якщо зображення не завантажиться — користувач побачить текст. Для скрінрідерів alt — єдиний спосіб дізнатись що зображено.

Адаптивні зображення

Різні зображення для різних розмірів екрану — менше трафіку, кращий Lighthouse.

srcset — різні розміри одного фото

<img
  src="photo-800.jpg"          <!-- fallback для старих браузерів -->
  srcset="photo-400.jpg 400w,  <!-- 400px ширина -->
          photo-800.jpg 800w,
          photo-1200.jpg 1200w"
  sizes="(max-width: 600px) 400px,
         (max-width: 900px) 800px,
         1200px"
  alt="Адаптивне фото"
/>

<picture> — різні формати або макети

<picture>
  <!-- Сучасний формат WebP для браузерів що підтримують -->
  <source type="image/webp" srcset="photo.webp" />

  <!-- Мобільне зображення (вертикальне) -->
  <source media="(max-width: 600px)" srcset="photo-mobile.jpg" />

  <!-- Fallback — обов'язковий! -->
  <img src="photo-desktop.jpg" alt="Фото" />
</picture>

Відео і аудіо

<video>

<video controls>
  <source src="video.mp4"
          type="video/mp4" />
  <source src="video.webm"
          type="video/webm" />
  Браузер не підтримує відео.
</video>

<!-- Атрибути -->
<video
  controls           <!-- панель керування -->
  autoplay muted     <!-- авто + без звуку -->
  loop               <!-- повтор -->
  poster="cover.jpg" <!-- обкладинка -->
></video>

<audio>

<audio controls>
  <source src="audio.mp3"
          type="audio/mpeg" />
  <source src="audio.ogg"
          type="audio/ogg" />
</audio>

<iframe> — YouTube

<iframe
  src="https://www.youtube.com/
       embed/VIDEO_ID"
  width="560"
  height="315"
  title="Назва відео"
  allowfullscreen
></iframe>

Формати зображень

ФорматКоли використовуватиПереваги
WebPБудь-які зображення (перший вибір)30-50% менше ніж JPEG при тій самій якості
JPEG / JPGФотографії, складні зображенняШирока підтримка, стиснення з втратами
PNGЗображення з прозорістю, скріншотиБез втрат якості, підтримує alpha-канал
SVGІконки, логотипи, ілюстраціїМасштабується без втрат, невеликий розмір
AVIFСучасні браузери (2023+)Найкраще стиснення, але не всі підтримують
GIFКороткі анімаціїКраще замінити WebP animated або <video>

Чотири шари

Content → Padding → Border → Margin — зовні всередину.

margin — зовнішній відступ
border — рамка
padding — внутрішній відступ
content — вміст
.box {
  /* Вміст */
  width: 200px;
  height: 100px;

  /* Padding — всередині */
  padding: 20px;               /* всі сторони */
  padding: 10px 20px;          /* верх/низ | ліво/право */
  padding: 10px 20px 5px 15px; /* верх право низ ліво */

  /* Border */
  border: 2px solid black;
  border-radius: 8px;          /* заокруглення */

  /* Margin — зовні */
  margin: 20px;
  margin: 0 auto;              /* авто = центрує по горизонталі */
}

box-sizing

Визначає чи входять padding і border у задану ширину.

content-box (за замовчуванням) ✗

.box {
  width: 200px;
  padding: 20px;
  border: 2px solid;
}
/* Реальна ширина = 200+40+4 = 244px */
/* НЕСПОДІВАНО! */
width: 100% + padding: 20px → виходить за межі

border-box (рекомендований) ✓

*, *::before, *::after {
  box-sizing: border-box;
}

.box {
  width: 200px;
  padding: 20px;
  border: 2px solid;
}
/* Реальна ширина = 200px — ЗАВЖДИ */
width: 100% з padding — залишається в межах

Display

Визначає як елемент розміщується в потоці документа.

/* Block — займає всю ширину, новий рядок (div, p, h1...) */
.el { display: block; }

/* Inline — як слово в тексті, ширина по вмісту (span, a) */
.el { display: inline; }

/* Inline-block — як inline, але можна задати width/height */
.el { display: inline-block; }

/* None — повністю прибирає елемент (займає 0 місця) */
.el { display: none; }
/* vs visibility: hidden — ховає але місце зберігає */

Злиття margin (margin collapse)

Вертикальні margin між сусідніми block-елементами зливаються в один — більший з двох.

h2 { margin-bottom: 30px; }
p  { margin-top: 20px; }

/* Відступ між h2 і p = 30px (НЕ 50px!) */
/* Береться більший з двох — це ЗЛИТТЯ */

/* Злиття НЕ відбувається для: */
/* - flex/grid елементів */
/* - елементів з padding або border між ними */
/* - горизонтальних margin */

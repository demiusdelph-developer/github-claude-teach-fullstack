Google Fonts — безкоштовні веб-шрифти

Найпростіший спосіб підключити кастомний шрифт. Вибираєш на fonts.google.com, копіюєш код.

Крок 1 — Підключення у <head>

<!-- Preconnect: браузер заздалегідь з'єднується з Google -->
<link rel="preconnect" href="https://fonts.googleapis.com" />
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />

<!-- Сам шрифт: Inter 400 і 700 ваги -->
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;700&display=swap"
      rel="stylesheet" />
preconnect — оптимізація. Без нього браузер чекає до першого запиту шрифту. З ним — починає з'єднання зразу.

Крок 2 — Використання у CSS

body {
  font-family: 'Inter', sans-serif;
  /* 'Inter' — назва шрифту (точно як у Google Fonts) */
  /* sans-serif — fallback, якщо шрифт не завантажився */
}

code, pre {
  font-family: 'JetBrains Mono', monospace;
}

/* Кілька шрифтів в одному URL через & */
/* family=Inter:wght@400;700&family=Roboto:wght@400 */

@font-face — власний шрифт із файлу

Коли шрифт знаходиться у твоєму проекті, а не на Google Fonts.

@font-face {
  font-family: 'MyFont';         /* своя назва */
  src: url('fonts/myfont.woff2') format('woff2'),
       url('fonts/myfont.woff')  format('woff');   /* fallback */
  font-weight: 400;
  font-style: normal;
  font-display: swap;            /* важливо! */
}

@font-face {
  font-family: 'MyFont';         /* та сама назва */
  src: url('fonts/myfont-bold.woff2') format('woff2');
  font-weight: 700;               /* окремо для жирного */
  font-display: swap;
}
woff2 — сучасний стиснутий формат, підтримується всіма браузерами. woff — старіший fallback для IE11. На нових проектах достатньо woff2.

font-display — як показувати текст до завантаження

Що бачить користувач поки шрифт ще завантажується.

ЗначенняЩо відбуваєтьсяКоли використовувати
swapПоказує системний шрифт → замінює на кастомнийМайже завжди — найкращий UX
blockХоває текст (~3с) → показує кастомнийУникай (FOIT — невидимий текст)
fallbackХоває (~100мс) → системний → кастомнийКомпроміс між swap і block
optionalХоває (~100мс) → якщо не встиг — системний назавждиНекритичні шрифти
Правило: для Google Fonts завжди додавай display=swap в URL. Без нього — браузер сам вирішує, зазвичай block.

display=swap у Google Fonts URL

<!-- Без display=swap — може бути невидимий текст -->
<link href="...?family=Inter:wght@400" ... />

<!-- З display=swap — завжди видимий текст -->
<link href="...?family=Inter:wght@400&display=swap" ... />

Типографічні властивості CSS

.text {
  font-family: 'Inter', system-ui, sans-serif;
  font-size: 16px;          /* або rem */
  font-weight: 400;          /* 100–900 */
  font-style: italic;        /* normal | italic | oblique */
  line-height: 1.6;          /* без одиниці — множник від font-size */
  letter-spacing: 0.05em;   /* між літерами */
  word-spacing: 4px;         /* між словами */
  text-align: left;          /* left | right | center | justify */
  text-transform: uppercase; /* uppercase | lowercase | capitalize */
  text-decoration: underline;/* none | underline | line-through */
  white-space: nowrap;       /* не переносити рядок */
  overflow: hidden;
  text-overflow: ellipsis;   /* "..." при обрізанні */
}

line-height — висота рядка

p {
  line-height: 1;     /* занадто тісно */
  line-height: 1.5;   /* нормально для UI */
  line-height: 1.6;   /* добре для читання — найчастіше */
  line-height: 2;     /* дуже широко */
  /* БЕЗ px/em/rem — як множник від font-size */
}

line-height: 1 (погано)

Цей текст дуже щільний і важко читати довгими реченнями. Рядки зливаються один з одним.

line-height: 1.6 (добре)

Цей текст зручний для читання. Між рядками є дихання, очі легко переходять на наступний рядок.

clamp() — fluid typography

Розмір тексту автоматично масштабується між мінімальним і максимальним значенням залежно від ширини екрана.

h1 {
  /* clamp(мінімум, ідеальне, максимум) */
  font-size: clamp(24px, 5vw, 48px);
  /* На малому екрані: 24px */
  /* На великому: 48px */
  /* Між ними: 5% від ширини вікна */
}

p {
  font-size: clamp(14px, 1.5vw, 18px);
}

/* min() і max() — окремо */
.container {
  width: min(800px, 90%);  /* менше з двох */
  font-size: max(14px, 1vw); /* більше з двох */
}

Зміни ширину вікна — текст масштабується (clamp(14px, 3vw, 28px))

Спробуй змінити ширину вікна браузера — розмір тексту адаптується автоматично без media queries.

Типовий стек типографіки для проекту

@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;600;700&display=swap');

:root {
  --font-body:    'Inter', system-ui, sans-serif;
  --font-mono:    'JetBrains Mono', monospace;

  --text-xs:  clamp(11px, 1.2vw, 12px);
  --text-sm:  clamp(13px, 1.4vw, 14px);
  --text-md:  clamp(15px, 1.6vw, 16px);
  --text-lg:  clamp(18px, 2vw,   22px);
  --text-xl:  clamp(24px, 3vw,   32px);
  --text-2xl: clamp(32px, 5vw,   48px);
}

body {
  font-family:  var(--font-body);
  font-size:    var(--text-md);
  line-height:  1.6;
}

Font stack — правильний порядок fallback

Браузер бере перший доступний шрифт зі списку.

body {
  /* Modern system UI stack */
  font-family: system-ui, -apple-system, BlinkMacSystemFont,
    'Segoe UI', Roboto, Oxygen, Ubuntu, sans-serif;

  /* З Google Fonts */
  font-family: 'Inter', system-ui, sans-serif;

  /* Monoscape stack */
  font-family: 'JetBrains Mono', 'Fira Code', 'Consolas', monospace;

  /* Serif stack */
  font-family: 'Merriweather', Georgia, 'Times New Roman', serif;
}

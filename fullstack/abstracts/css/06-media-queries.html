Медіа-запити

Змінюють стилі залежно від розміру вікна, орієнтації, теми системи. Основа адаптивного дизайну.

← 05 — Grid 07 — Анімації →

Синтаксис

@media (умова) {
  /* стилі що застосуються тільки при цій умові */
  .container { padding: 16px; }
}

/* Комбінації умов */
@media (min-width: 768px) and (max-width: 1023px) {
  /* тільки для планшетів */
}

@media (max-width: 767px), (orientation: portrait) {
  /* одна умова АБО інша (кома = OR) */
}

Стандартні розміри для різних пристроїв.

/* Мобільні — до 767px */
@media (max-width: 767px) {
  .container { padding: 16px; }
}

/* Планшети — 768px до 1023px */
@media (min-width: 768px) and (max-width: 1023px) {
  .container { padding: 24px; }
}

/* Десктоп — від 1024px */
@media (min-width: 1024px) {
  .container { padding: 40px; }
}

Mobile First — правильний підхід

Пиши стилі спочатку для мобільних, потім розширюй для більших екранів через min-width.

✗ Desktop First (застарілий)

/* Base = desktop */
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
}

/* Потім скорочуємо для мобільних */
@media (max-width: 767px) {
  .cards {
    grid-template-columns: 1fr;
  }
}

✓ Mobile First (сучасний)

/* Base = mobile */
.cards {
  display: flex;
  flex-direction: column;
  gap: 16px;
}

/* Розширюємо для більших */
@media (min-width: 768px) {
  .cards {
    flex-direction: row;
    flex-wrap: wrap;
  }
}

@media (min-width: 1024px) {
  .cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
  }
}

Чому Mobile First?

Більшість користувачів — з мобільного. Браузери мобільних завантажують Base CSS завжди; медіа-запити — тільки якщо умова виконується. Mobile First = менше CSS для мобільних.

Viewport meta — обов'язково!

Без цього тегу мобільні браузери масштабують сторінку і медіа-запити не спрацьовують правильно.

<!-- У <head> кожної HTML-сторінки -->
<meta name="viewport" content="width=device-width, initial-scale=1.0" />

Інші умови медіа-запитів

/* Орієнтація пристрою */
@media (orientation: portrait)  { /* вертикально */ }
@media (orientation: landscape) { /* горизонтально */ }

/* Темна тема системи */
@media (prefers-color-scheme: dark) {
  body { background: #111; color: #fff; }
}

/* Зменшення анімацій (вестибулярні порушення) */
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}

/* Роздільна здатність (Retina-дисплеї) */
@media (min-resolution: 2dppx) {
  /* використати @2x зображення */
}

/* Друк */
@media print {
  .navbar, .sidebar { display: none; }
  body { font-size: 12pt; color: black; }
}

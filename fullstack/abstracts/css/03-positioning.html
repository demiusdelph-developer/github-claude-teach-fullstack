static — за замовчуванням

Елемент стоїть там де він є в HTML. Властивості top/left/right/bottom не мають ефекту.

.el {
  position: static; /* за замовч., можна не писати */
  top: 20px; /* не матиме ефекту! */
}

relative — відносний

Зміщується відносно своєї нормальної позиції. Важливо: місце в потоці зберігається — сусідні елементи не "бачать" зміщення.

.el {
  position: relative;
  top: 20px;   /* зміщується вниз на 20px */
  left: 30px;  /* зміщується вправо на 30px */
}

/* Головне застосування — стати батьком для absolute-нащадка */
.card { position: relative; } /* бейдж прив'яжеться до картки */

Зміщення без виходу з потоку

Блок 1 (static)
Блок 2 (relative: top:10px left:20px) — зміщений але місце резервується
Блок 3 — стоїть нижче як ніби блок 2 на місці

absolute — абсолютний

Вириває елемент з потоку. Позиціонується відносно найближчого батька з position ≠ static. Якщо такого немає — відносно <html>.

.card {
  position: relative; /* ← обов'язково! батько для бейджа */
}

.badge {
  position: absolute;
  top: -12px;   /* від верхнього краю батька */
  right: -12px; /* від правого краю батька */
  /* виходить за межі батька */
}

Якщо на батькові немає position: relative — бейдж позиціонується відносно <html> і "улетить" в куток сторінки.

fixed — фіксований

Позиціонується відносно вікна браузера. Не прокручується разом зі сторінкою — завжди видимий.

.btn-top {
  position: fixed;
  bottom: 24px;
  right: 24px;
  z-index: 10;  /* поверх іншого вмісту */
}

.navbar-sticky {
  position: fixed;
  top: 0;
  left: 0;
  right: 0; /* або width: 100% */
  z-index: 100;
}

sticky — прилипаючий

Залишається в потоці поки не досягне порогу прокрутки — тоді "прилипає".

.section-header {
  position: sticky;
  top: 0;  /* прилипає коли досягає верху */
  background: white; /* потрібен фон! */
  z-index: 10;
}

/* Батько ОБОВ'ЯЗКОВО повинен мати висоту більше ніж sticky-елемент */
/* і не мати overflow: hidden */

z-index — порядок накладення

Більше число — елемент поверх. Працює тільки на елементах з position ≠ static.

.backdrop { z-index: 10; }   /* напівпрозорий фон */
.modal    { z-index: 20; }   /* поверх фону */
.tooltip  { z-index: 30; }   /* найвище */

/* Рекомендовані значення для проекту (кратні 10): */
/* navbar: 100, modal-backdrop: 200, modal: 300, toast: 400 */

top / right / bottom / left

Відступи від відповідного краю. Можуть бути від'ємними щоб вийти за межі батька.

.el {
  position: absolute;

  top: 0;      /* від верхнього краю батька */
  right: 0;    /* від правого краю */
  bottom: 0;   /* від нижнього краю */
  left: 0;     /* від лівого краю */

  /* top:0 + left:0 + right:0 + bottom:0 = розтягнути на весь батько */

  top: -12px;  /* виходить за верхній край батька на 12px */
}

Змінні (Custom Properties)

CSS-змінні зберігають значення в одному місці — змінюєш в одному місці, змінюється скрізь. Ключ до масштабованого коду.

Оголошення і використання

/* Оголошення — зазвичай у :root щоб були глобальними */
:root {
  --color-primary: #3b82f6;
  --color-text: #111827;
  --color-bg: #ffffff;

  --font-size-base: 16px;
  --font-size-lg: 20px;

  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 32px;

  --border-radius: 8px;
  --shadow: 0 2px 8px rgba(0, 0, 0, 0.1);
}

/* Використання — через функцію var() */
.button {
  background: var(--color-primary);
  padding: var(--spacing-sm) var(--spacing-md);
  border-radius: var(--border-radius);
  font-size: var(--font-size-base);
}

/* var() з запасним значенням якщо змінна не визначена */
.card {
  color: var(--color-text, black);
}

Хороший нейминг змінних

/* По семантиці (рекомендовано) — що значить, не як виглядає */
:root {
  --color-primary: #3b82f6;   /* ✓ */
  --color-blue: #3b82f6;       /* ✗ — якщо зміниш на зелений, ім'я хибне */

  --font-size-body: 16px;      /* ✓ */
  --size-16: 16px;             /* ✗ — неочевидно для чого */
}

/* Система spacing */
:root {
  --space-1: 4px;
  --space-2: 8px;
  --space-3: 12px;
  --space-4: 16px;
  --space-6: 24px;
  --space-8: 32px;
}

Темна тема через змінні

Перевизначаєш змінні в одному місці — весь сайт змінює тему.

:root {
  --bg: #ffffff;
  --text: #111827;
  --surface: #f3f4f6;
  --primary: #3b82f6;
}

@media (prefers-color-scheme: dark) {
  :root {
    --bg: #0f172a;        /* ← тільки тут змінюємо */
    --text: #f1f5f9;
    --surface: #1e293b;
    --primary: #60a5fa;
  }
}

/* Весь інший код залишається без змін */
body  { background: var(--bg); color: var(--text); }
.card { background: var(--surface); }

Локальні змінні

Змінна може бути тільки для одного компонента — і дочірні мають до неї доступ.

.card {
  --card-padding: 24px;   /* локальна — тільки для .card */
  --card-bg: #f9fafb;

  padding: var(--card-padding);
  background: var(--card-bg);
}

/* Дочірні теж мають доступ */
.card .title {
  padding-bottom: calc(var(--card-padding) / 2); /* 12px */
}

calc() — обчислення

Дозволяє змішувати одиниці і виконувати математику прямо в CSS.

.container {
  width: calc(100% - 40px);               /* повна ширина мінус відступи */
  height: calc(100vh - 80px);             /* на всю висоту мінус хедер */
  font-size: calc(var(--font-size-base) * 1.25); /* 20px */
  padding: calc(var(--spacing-md) * 2);  /* 32px */
  grid-template-columns: calc(50% - 8px) calc(50% - 8px); /* два рівні стовпці з gap 16px */
}

Зміна змінних через JavaScript

// Встановлення змінної
document.documentElement.style.setProperty('--color-primary', '#ef4444');

// Читання значення
const value = getComputedStyle(document.documentElement)
  .getPropertyValue('--color-primary'); // "#3b82f6"

// Практичний приклад — перемикач теми
document.querySelector('.theme-btn').addEventListener('click', () => {
  document.documentElement.classList.toggle('dark');
});

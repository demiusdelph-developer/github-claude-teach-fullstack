Grid

Двовимірне розміщення — рядки і стовпці одночасно. Grid ідеальний для складних макетів сторінок і адаптивних сіток.

Вмикаємо grid

.container {
  display: grid;

  /* Визначення стовпців */
  grid-template-columns: 200px 200px 200px; /* 3 фіксовані */
  grid-template-columns: 1fr 2fr 1fr;      /* fr — частка простору */
  grid-template-columns: repeat(3, 1fr);   /* скорочення */

  /* Визначення рядків */
  grid-template-rows: 80px auto 60px;

  /* Відстань */
  gap: 16px;           /* між рядками і стовпцями */
  column-gap: 24px;
  row-gap: 16px;
}

Одиниця fr — частка вільного простору

fr = fraction. Ділить доступний простір пропорційно.

grid-template-columns: 1fr 1fr 1fr;   /* три рівні стовпці */
grid-template-columns: 1fr 2fr 1fr;   /* середній вдвічі ширший */
grid-template-columns: 200px 1fr;     /* sidebar фіксований, main — решта */

repeat() + minmax() — адаптивна сітка

Найпотужніша комбінація — автоматично визначає кількість стовпців без медіа-запитів.

.cards {
  display: grid;

  /* auto-fill — заповнює стільки стовпців скільки влізе */
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));

  /* auto-fit — те саме але порожні треки стискаються до 0 */
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));

  gap: 16px;
}
/* При широкому вікні = 3+ колонки */
/* При вузькому вікні = 1-2 колонки автоматично */

Розміщення елементів

Елемент може займати декілька стовпців і рядків.

.item {
  /* По стовпцях: від лінії / до лінії */
  grid-column: 1 / 3;    /* від 1 до 3 (займає 2 стовпці) */
  grid-column: 1 / -1;   /* від першої до ОСТАННЬОЇ лінії */
  grid-column: span 2;   /* займає 2 стовпці (з поточної позиції) */

  /* По рядках */
  grid-row: 1 / 3;       /* займає 2 рядки */
  grid-row: span 2;
}

grid-template-areas — іменовані зони

Найнаочніший спосіб описати макет сторінки — візуально в коді.

.page {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: 64px 1fr 48px;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
  gap: 0;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }

/* . — порожня клітинка */
grid-template-areas:
    "header header"
    ".      main";  /* без sidebar */

## Що тренуємо (по конспекту CSS)

### Основи CSS — Розділ 1
- **Підключення зовнішнього файлу** через `<link rel="stylesheet">` (не inline, не `<style>`)
- **Синтаксис:** селектор `{ властивість: значення; }`
- **Селектори тегів:** `body`, `h1`, `h2`, `p`, `ul`, `a` — стилізуєш HTML елементи напряму
- **Селектор класу:** `.card` — для самої картки
- **Псевдоклас `:hover`:** `a:hover` — підкреслення при наведенні
- **Кольори:** HEX (`#3b82f6`) або назва (`cornflowerblue`) — для фону і тексту
- **Одиниці:** `px` для розмірів, `rem` або `px` для шрифтів

### Блокова модель — Розділ 2
- **`box-sizing: border-box`** — обов'язковий reset на початку стилів
- **`margin: 0; padding: 0`** — скидання відступів браузера
- **`padding`** — внутрішні відступи картки (щоб текст не прилипав до країв)
- **`width` / `max-width`** — обмеження ширини картки (наприклад `max-width: 480px`)
- **`border-radius`** — заокруглені кути картки

### Flexbox — Розділ 4
- **`display: flex`** на `body` — щоб картка розміщувалась по центру
- **`justify-content: center`** — центр по горизонталі
- **`align-items: center`** — центр по вертикалі
- **`min-height: 100vh`** — щоб `body` займало всю висоту екрана

## Вимоги

### HTML
Сторінка повинна містити:

- `<!DOCTYPE html>` та правильну структуру документа (`html`, `head`, `body`)
- Мета-теги: `charset`, `viewport`, `description`
- `<title>` — твоє ім'я або нікнейм
- Всередині `<body>` — один блок-картка (`<article>` або `<section>`) з:
  - Твоїм ім'ям у тегу `<h1>`
  - Підзаголовком — ким ти хочеш стати (наприклад: "Junior Full Stack Developer") у тегу `<p>` або `<h2>`
  - Коротким текстом про себе (2–3 речення) у тегу `<p>`
  - Списком навичок `<ul>` з мінімум 3 пунктами `<li>` (наприклад: HTML, CSS, Git)
  - Посиланням `<a>` (можна фейкове: `href="#"`) з текстом "Зв'язатись зі мною"

### CSS
Підключи окремий файл `style.css` (не пиши стилі прямо в HTML).  
Сторінка повинна мати:

- Колір фону для всієї сторінки (не білий)
- Картка по центру сторінки (використай Flexbox на `body`)
- Картка з білим або світлим фоном, відступами (`padding`) і заокругленими кутами (`border-radius`)
- Ширина картки обмежена через `max-width` (десь 420–500px), але не фіксована через `width` — чому саме так, розберемо на розборі
- Заголовок `h1` — інший колір або розмір ніж стандартний
- Посилання без підкреслення за замовчуванням, але з підкресленням при наведенні (`hover`)

### Теми які обговорювали

**Семантика HTML**
- `<article>` — для самодостатнього контенту, не тільки для статей
- `<section>` — тематичний блок всередині `<article>`, завжди з заголовком
- Заголовки як структура: `<h2>` тільки там де починається новий розділ — підпис до імені це `<p>`, не `<h2>`
- `<a>` vs `<button>` — посилання переходить кудись, кнопка виконує дію

**Назви класів**
- Називати по ролі елемента, не по вигляду: `.card-subtitle` а не `.header-3`
- BEM (`.card__subtitle`) — стандарт у великих проектах, варто вміти читати
- Для невеликих проектів достатньо простої семантичної назви: `.card-title`, `.card-bio`

**Margin collapsing (схлопування марджинів)**
- Вертикальні марджини сусідніх блоків не додаються — перемагає більший
- Не відбувається у flex/grid контейнерах
- Горизонтальні марджини ніколи не схлопуються

**Display і inline елементи**
- `inline` — ігнорує `margin-top/bottom` і вертикальний `padding`
- `inline-block` — поважає всі марджини, займає лише свою ширину
- `inline-flex` — те саме що `inline-block`, але всередині flex контейнер
- `flex` і `block` — розтягуються на всю ширину батька

**`max-width` vs `width`**
- `width: 400px` — завжди 400px, навіть якщо екран вужчий (зламає мобільний)
- `max-width: 400px` — максимум 400px, але може бути вужче — правильний підхід для карток

**`text-decoration-skip-ink`**
- Браузер за замовчуванням обходить підкреслення навколо хвостиків літер
- Вимкнути: `text-decoration-skip-ink: none`

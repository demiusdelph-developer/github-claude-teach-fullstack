Задача / 02

Позиціонування (position)

⏱ 45–75 хвилин 📚 CSS / 03 — Позиціонування 🎯 Початковий+

Береш картку з задачі 01 і додаєш бейдж та фіксовану кнопку через position.

Що будеш робити

  1. Бейдж — кольоровий ярлик "Open to work ✓" у верхньому правому куті картки
  2. Кнопка "↑" — фіксована кнопка внизу праворуч, завжди видима при скролі
  3. Скопіюй картку 4–5 разів, щоб сторінка прокручувалась

Макет

Картка з бейджем:

┌───────────────────────┐ │ ┌───────────────┐ │ Дмитро │ Open to work │ │ Junior Dev │ ✓ │ │ └───────────────┘ │ Текст... │ │ [ Зв'язатись ] │ └───────────────────────┘

Фіксована кнопка:

┌──────────────────────┐ │ сторінка прокручується│ │ │ │ ┌──┐ │ │ │↑ │ ← fixed │ └──┘ │ └──────────────────────┘
🖼 Відкрити HTML-макет у новій вкладці

Що тренуємо

ВластивістьЩо робить
position: relativeЗалишається в потоці, стає контекстом для absolute
position: absoluteВиривається з потоку, позиціонується відносно relative-батька
position: fixedВідносно вікна браузера, не прокручується
top / right / bottom / leftЗміщення від відповідного краю
z-indexПорядок накладення: більше число — поверх

Вимоги — HTML

  • Скопіюй структуру картки з задачі 01
  • Всередині картки після <h1> — <span class="badge">Open to work ✓</span>
  • Нижче карток — <button class="btn-top">↑</button>
  • Ще 4 копії картки щоб сторінка прокручувалась

Вимоги — CSS

/* 1. Картка — потрібна для бейджа */
.card { position: relative; }

/* 2. Бейдж */
.badge {
  position: absolute;
  top: -12px;
  right: -12px;
}

/* 3. Фіксована кнопка */
.btn-top {
  position: fixed;
  bottom: 24px;
  right: 24px;
  z-index: 10;
}
Body вже має display: flex з задачі 01 — додай flex-direction: column і align-items: center щоб картки йшли колонкою.

Перевір себе

  • Бейдж виходить за межі картки? — Саме так і повинно бути
  • При скролі вниз кнопка "↑" залишається на місці?
  • Прибери position: relative з .card — куди переїхав бейдж? Зрозумій чому.

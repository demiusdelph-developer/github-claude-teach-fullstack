Вимоги — HTML

  • <!DOCTYPE html> та правильна структура (html, head, body)
  • Мета-теги: charset, viewport, description
  • <title> — твоє ім'я або нікнейм
  • Блок-картка <article class="card"> з ім'ям у <h1>
  • Підзаголовок у <p class="subtitle"> (не h2!)
  • Короткий текст про себе у <p>
  • Список навичок <ul> з мінімум 3 пунктами <li>
  • Посилання <a href="#"> з текстом "Зв'язатись зі мною"
<body>
  <article class="card">
    <h1>Ім'я Прізвище</h1>
    <p class="subtitle">Junior Full Stack Developer</p>
    <p>Текст про себе...</p>
    <ul>
      <li>HTML</li>
      <li>CSS</li>
      <li>Git</li>
    </ul>
    <a href="#">Зв'язатись зі мною</a>
  </article>
</body>

Вимоги — CSS

Підключи окремий файл style.css через <link> — не пиши стилі прямо в HTML.
  • CSS reset: *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }
  • Колір фону для всієї сторінки (не білий)
  • Картка по центру через Flexbox на body
  • min-height: 100vh на body щоб займало весь екран
  • Картка з padding, border-radius, max-width: 420–500px
  • Заголовок h1 — інший колір або розмір
  • Посилання без підкреслення за замовчуванням, але з :hover
/* Центрування картки */
body {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh;
}

.card {
  background: white;
  padding: 32px;
  border-radius: 12px;
  max-width: 460px;
  width: 100%;
}

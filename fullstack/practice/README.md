# Практика

## Як це працює

1. Кожна задача знаходиться у своїй папці: `task-01/`, `task-02/` тощо
2. Всередині папки є файл `task.md` — це умова задачі з повним описом
3. Ти самостійно виконуєш задачу і кладеш свої файли **поруч** з `task.md` у ту саму папку
4. Коли готовий — кажеш мені, я перевіряю і даю повний розбір

## Правила

- Не підглядати в готові приклади і не копіювати з `my-project/`
- Спочатку спробуй сам — застряг більше ніж на 20 хвилин, тоді питай підказку
- Після кожної задачі ми робимо висновки: що вийшло, що ні, що запам'ятати

# Задача 04 — CSS Grid

**Тема:** Розділ 5 — display: grid, grid-template-columns/rows, grid-template-areas, grid-area, grid-column: span, gap  
**Орієнтовний час:** 60–90 хвилин  
**Рівень:** Початковий+

---

## Що будеш робити

Побудуєш сторінку блогу з трьох зон:

1. **Шапка (header)** — на всю ширину: назва сайту зліва, навігація справа (Flexbox з минулого таску)
2. **Двоколонковий макет** — вузький сайдбар зліва + основний контент справа
3. **Сітка постів** — чотири картки поста, де **одна займає дві колонки**
4. **Підвал (footer)** — на всю ширину

---

## Макет

```

│  HEADER: MyBlog              Головна  Про  Теги │
```

## Що тренуємо

| Властивість | Де застосовуємо |
|---|---|
| `display: grid` | сторінка + сітка постів |
| `grid-template-columns: 220px 1fr` | сторінка: фіксований сайдбар + гнучкий main |
| `grid-template-rows: auto 1fr auto` | шапка, контент, підвал |
| `grid-template-areas` | іменовані зони layout |
| `grid-area` | прив'язати елемент до зони |
| `grid-template-columns: repeat(2, 1fr)` | сітка постів: рівні колонки |
| `grid-column: span 2` | Пост 3 займає обидві колонки |
| `gap` | відступи між усіма grid-елементами |

### CSS

**Layout сторінки:**
```css
body {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar posts"
    "footer  footer";
  min-height: 100vh;
  gap: 0; /* відступи між зонами — за бажанням */
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.posts   { grid-area: posts; }
.footer  { grid-area: footer; }
```

**Шапка (використай Flexbox — вже знаєш):**
```css
.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  /* padding, background — на твій смак */
}
```

**Сітка постів:**
```css
.posts {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 24px;
  /* padding — щоб не злипалось */
}

.post--featured {
  grid-column: span 2; /* займає обидві колонки */
}
```

## Різниця між Grid і Flexbox

Коли думати про Grid, а коли — про Flexbox:

| | Flexbox | Grid |
|---|---|---|
| **Напрямок** | один вимір (рядок **або** стовпець) | два виміри (рядки **і** стовпці) |
| **Застосування** | navbar, ряд кнопок, картки в рядок | layout сторінки, фото-галерея, таблиця |
| **Контроль** | елементи самі визначають розмір | ти задаєш точну сітку заздалегідь |

У цій задачі використовуємо **обидва**: Grid для layout (де стоять зони) і Flexbox для шапки (де стоять елементи всередині зони).

Помилки які були знайдені

Помилка #1 — lang="en" на українській сторінці

Правильно: lang="uk" — браузер і пошуковики визначають мову документа саме з цього атрибута.

Помилка #2 — <h2> для підзаголовка замість <p>

"Junior Full Stack Developer" — це підпис, не новий розділ. Правильно: <p class="card-subtitle">.

Помилка #3 — відсутній CSS reset

Завжди починай з: *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }

Помилка #4 — height: 100vh замість min-height

height: 100vh — фіксована висота, контент обріжеться. min-height: 100vh — правильно.

Помилка #5 — text-decoration: underline на кнопці

Для елементів стилізованих як кнопка — підкреслення виглядає погано. Краще: зміна фону або transform: translateY(-1px) при hover.

Теми які обговорювали

Семантика HTML

  • <article> — для самодостатнього контенту, не тільки для статей
  • Заголовки h1–h6 позначають структуру, а не вигляд
  • <a> vs <button> — посилання переходить кудись, кнопка виконує дію

Назви класів — по ролі, не по вигляду

  • .card-subtitle — правильно (роль елемента)
  • .header-3 — неправильно (описує вигляд)

Margin collapsing — схлопування марджинів

  • Вертикальні марджини сусідніх блоків не додаються — перемагає більший
  • Не відбувається у flex/grid контейнерах

max-width vs width

  • width: 400px — завжди 400px, навіть якщо екран вужчий (зламає мобільний)
  • max-width: 400px — максимум 400px, але може бути вужче ✓

Прогрес — що з'явилось у цій задачі

Перша задача — все будується з нуля. Базові блоки які будемо використовувати у всіх наступних задачах.

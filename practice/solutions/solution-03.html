Що було зроблено

  • Навбар з SVG-лого зліва і навігацією справа (justify-content: space-between)
  • Сітка з 4 карток з переносом по 3 в рядок (flex-wrap: wrap)
  • Кнопка "↑" фіксована в правому нижньому куті (position: fixed)
  • Список навичок переноситься при нестачі місця (flex-wrap: wrap на ul)

Додатково до умови

Точна формула ширини картки замість flex: 1 1 280px

/* Умова задачі: */
.card { flex: 1 1 280px; max-width: 360px; }

/* Точніше рішення: */
.articles article {
  flex: 0 1 calc((100% - 80px) / 3);
  min-width: 0;
}
/* 100% - 80px = контейнер мінус два gap по 40px → / 3 */

Теми які обговорювали

flex-grow і одинока картка в рядку

  • flex-grow: 1 — займає весь вільний простір у рядку
  • 3 картки: простір ділиться рівно — добре
  • 1 картка: розтягується на всю ширину — не завжди бажано
  • Рішення: flex: 0 1 calc(...) або max-width

min-width: 0 на flex-елементі

  • За замовчуванням flex-елемент не може звужуватись нижче ширини свого контенту (min-width: auto)
  • min-width: 0 знімає це обмеження

Відсотки vs пікселі у flex-basis

  • flex: 1 1 20% — непередбачуваний з gap у пікселях
  • flex: 1 1 280px — фіксований мінімум, стабільніше
  • calc((100% - gap*(n-1)) / n) — найточніший варіант

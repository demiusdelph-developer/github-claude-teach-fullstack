Flexbox — навбар і сітка карток

⏱ 60–90 хвилин 📚 CSS / 04 — Flexbox 🎯 Початковий+

Побудуєш міні-сторінку з навбаром і адаптивною сіткою карток профілю.

Що будеш робити

  1. Навбар — горизонтальна панель: лого зліва, посилання справа
  2. Сітка карток — три картки профілю в рядок, які переносяться при нестачі місця

Макет

Навбар:

┌─────────────────────────────────────────────────────┐ │ MyPortfolio Про мене Проекти Контакти │ └─────────────────────────────────────────────────────┘ ↑ лого (зліва) ↑ посилання (справа)

Сітка карток (при звуженні переносяться):

┌─────────────┐ ┌─────────────┐ ┌─────────────┐ │ Картка 1 │ │ Картка 2 │ │ Картка 3 │ │ Ім'я │ │ Ім'я │ │ Ім'я │ │ Текст... │ │ Текст... │ │ Текст... │ │ [Кнопка] │ │ [Кнопка] │ │ [Кнопка] │ └─────────────┘ └─────────────┘ └─────────────┘
🖼 Відкрити HTML-макет у новій вкладці

Що тренуємо

ВластивістьДе застосовуємо
display: flexнавбар і контейнер карток
justify-content: space-betweenнавбар (лого зліва, лінки справа)
align-items: centerвирівняти елементи навбару по висоті
flex-wrap: wrapперенос карток на новий рядок
gapвідстань між картками
flex: 1 1 280pxкартка: мінімум 280px, може рости

Вимоги — HTML

<body>
  <header class="navbar">
    <span class="logo">MyPortfolio</span>
    <nav class="nav-links">
      <a href="#">Про мене</a>
      <a href="#">Проекти</a>
      <a href="#">Контакти</a>
    </nav>
  </header>
  <main class="cards-grid">
    <article class="card"> ... </article>
    <article class="card"> ... </article>
    <article class="card"> ... </article>
  </main>
</body>

Вимоги — CSS

/* Навбар */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
.nav-links { display: flex; gap: 24px; }

/* Сітка карток */
.cards-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
  justify-content: center;
}
.card { flex: 1 1 280px; max-width: 360px; }

Перевір себе

  • Лого і посилання знаходяться на одній горизонтальній лінії?
  • Посилання навбару стоять в рядок (не стовпцем)?
  • Три картки в рядок при широкому вікні?
  • Звузь вікно браузера до ~600px — картки переносяться вниз, не здавлюються?
  • Між картками є відступ (gap)?
💡 Питання для роздумів: Що станеться якщо прибрати flex-wrap: wrap з .cards-grid? Спробуй.

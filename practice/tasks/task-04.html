CSS Grid — layout сторінки і сітка постів

⏱ 60–90 хвилин 📚 CSS / 05 — Grid 🎯 Початковий+

Побудуєш сторінку блогу з layout через grid-template-areas та сіткою постів, де один пост займає дві колонки.

Що будеш робити

  1. Шапка (header) — на всю ширину: назва сайту зліва, навігація справа (Flexbox з таску 03)
  2. Двоколонковий макет — вузький сайдбар зліва + основний контент справа
  3. Сітка постів — п'ять карток, де один пост займає дві колонки
  4. Підвал (footer) — на всю ширину

Макет

Загальний layout (grid-template-areas):

Що тренуємо

ВластивістьДе застосовуємо
display: gridbody (layout сторінки) і main.posts (сітка)
grid-template-columns: 220px 1frфіксований сайдбар + гнучкий main
grid-template-rows: auto 1fr autoшапка, контент, підвал
grid-template-areasіменовані зони layout сторінки
grid-areaприв'язати елемент до зони
grid-template-columns: repeat(2, 1fr)сітка постів — рівні колонки
grid-column: span 2Пост 3 займає обидві колонки
gapвідступи між усіма grid-елементами

Вимоги — CSS

/* Layout сторінки */
body {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar posts"
    "footer  footer";
  min-height: 100vh;
}
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.posts   { grid-area: posts; }
.footer  { grid-area: footer; }

/* Шапка (Flexbox — вже знаєш) */
.header { display: flex; justify-content: space-between; align-items: center; }

/* Сітка постів */
.posts {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 24px;
  padding: 24px;
}
.post--featured { grid-column: span 2; }

Перевір себе

  • Сайдбар зліва, пости справа — завдяки grid-template-areas?
  • Шапка і підвал на всю ширину (обидві колонки)?
  • Пост 3 займає весь рядок (обидві колонки)?
  • Між постами є відступ (gap)?
  • Сайдбар не розтягується по горизонталі — 220px фіксовано?
💡 Питання для роздумів: Що станеться, якщо прибрати grid-column: span 2 з .post--featured? Спробуй.

Grid vs Flexbox

FlexboxGrid
Напрямокодин вимір (рядок або стовпець)два виміри (рядки і стовпці)
Застосуванняnavbar, ряд кнопок, карткиlayout сторінки, галерея
Контрольелементи самі визначають розмірти задаєш точну сітку заздалегідь
У цій задачі використовуємо обидва: Grid для layout (де стоять зони) і Flexbox для шапки (де стоять елементи всередині зони).

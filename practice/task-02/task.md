## Що тренуємо (Розділ 3 конспекту)

| Властивість | Що робить |
|---|---|
| `position: relative` | Елемент залишається в потоці, але стає **контекстом** для `absolute` дочірніх |
| `position: absolute` | Виривається з потоку, позиціонується відносно найближчого батька з `position != static` |
| `position: fixed` | Відносно вікна браузера — не прокручується разом зі сторінкою |
| `top / right / bottom / left` | Зміщення від відповідного краю |
| `z-index` | Порядок накладення: більше число — поверх |

## Вимоги

### HTML

- Скопіюй структуру картки з задачі 01
- Всередині картки додай `<span class="badge">Open to work</span>` — прямо після `<h1>`
- Нижче картки (але теж в `<body>`) — ще 4 копії тієї ж картки (просто дублюй HTML-блок), щоб сторінка прокручувалась
- Після всіх карток — `<button class="btn-top">↑</button>`

### CSS

**Картка (зміна з задачі 01):**
```css
.card {
  position: relative; /* потрібно щоб бейдж позиціонувався відносно картки */
  /* решту стилів залиш як було */
}
```

**Бейдж:**
```css
.badge {
  position: absolute;
  top: -12px;
  right: -12px;
  /* колір, padding, border-radius — на твій смак */
}
```

**Фіксована кнопка:**
```css
.btn-top {
  position: fixed;
  bottom: 24px;
  right: 24px;
  z-index: 10;
  /* колір, розмір, border-radius — на твій смак */
}
```

**Body:**  
Щоб картки не злипались — додай `gap` або `margin-bottom` між ними. Body вже має `display: flex` з задачі 01 — тепер зміни його на `flex-direction: column` і `align-items: center`.

### Теми які обговорювали

**Селектори: крапка vs без крапки**
- `.article` — клас-селектор, шукає елементи з `class="article"`
- `article` — тег-селектор, шукає всі теги `<article>`
- `article.card` — тег `<article>` який також має клас `.card`
- `.card:first-child` — простіший варіант замість `nth-child(1)`

**`position: absolute` і поток документа**
- `absolute` повністю вириває елемент з потоку — сусідні елементи його "не бачать"
- `margin`, `padding` на absolute-елементі не впливають на розміщення інших елементів
- `display` встановлюється автоматично — `inline-block` зайвий

**Пара `relative` + `absolute`**
- `position: absolute` позиціонується відносно **найближчого батька** у якого `position != static`
- Якщо такого батька немає — позиціонується відносно `<html>`
- Тому `position: relative` на батьку — обов'язковий крок

**`position: fixed`**
- Позиціонується відносно вікна браузера, не сторінки
- Не прокручується разом з контентом
- Завжди потребує `z-index` якщо може перекриватись з іншими елементами

**`padding-top` на body vs `margin-top` на першому елементі**
- `padding-top` на body дає відступ зверху для всього контенту
- `margin-top` на першому елементі — вузьке рішення, не захищає інші картки

**Unicode-символи в HTML**
- `✓` і `↑` — звичайні символи Unicode, вставляються прямо в текст
- Альтернатива: HTML-ентіті `&#10003;` для `✓`
- SVG-іконки — для складніших випадків, бібліотеки Heroicons / Lucide

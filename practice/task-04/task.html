ЗАДАЧА 04

CSS Grid

Тема: display: grid, grid-template-areas, grid-column: span Час: 60–90 хвилин Рівень: Початковий+

Що будеш робити

Побудуєш сторінку блогу з чотирьох зон:

  1. Шапка (header) — на всю ширину: назва сайту зліва, навігація справа (Flexbox з минулого таску)
  2. Двоколонковий макет — вузький сайдбар зліва + основний контент справа
  3. Сітка постів — п'ять карток, де один пост займає дві колонки
  4. Підвал (footer) — на всю ширину

CSS — стартова основа

Layout сторінки

body {
  display: grid;
  grid-template-columns: 220px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar posts"
    "footer  footer";
  min-height: 100vh;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.posts   { grid-area: posts; }
.footer  { grid-area: footer; }

Шапка (Flexbox — вже знаєш)

.header {
  display: flex;
  justify-content: space-between;
  align-items: center;
  /* padding, background — на твій смак */
}

Сітка постів

.posts {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 24px;
  padding: 24px;
}

.post--featured {
  grid-column: span 2; /* займає обидві колонки */
}

Що НЕ потрібно

  • Медіа-запити (адаптивність — наступна тема)
  • JavaScript
  • Реальні зображення в постах — тільки текст і теги
  • Складна типографіка

Перевір себе

  • Сайдбар зліва, пости справа — завдяки grid-template-areas?
  • Шапка і підвал на всю ширину?
  • Пост 3 займає весь рядок (обидві колонки)?
  • Між постами є gap?
  • Сайдбар не розтягується — 220px фіксовано?
Питання для роздумів: Що станеться, якщо прибрати grid-column: span 2 з .post--featured? Спробуй.

Grid vs Flexbox — коли що

FlexboxGrid
Напрямокодин вимір (рядок або стовпець)два виміри (рядки і стовпці)
Застосуванняnavbar, ряд кнопок, картки в рядокlayout сторінки, галерея, таблиця
Контрольелементи самі визначають розмірти задаєш точну сітку заздалегідь
У цій задачі використовуємо обидва: Grid для layout (де стоять зони) і Flexbox для шапки (де стоять елементи всередині зони).

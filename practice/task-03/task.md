**Тема:** Розділ 4 — display: flex, justify-content, align-items, flex-wrap, gap, flex

## Що будеш робити

Побудуєш міні-сторінку з двох частин:

1. **Навбар** — горизонтальна панель: лого зліва, посилання справа
2. **Сітка карток** — три картки профілю в рядок, які переносяться при нестачі місця

Картку профілю вже знаєш — використовуй спрощену версію з задачі 01 (без бейджа і фіксованої кнопки, просто ім'я + текст + кнопка).

```

└─────────────┘  └─────────────┘  └─────────────┘
```

При звуженні вікна картки мають переноситись на новий рядок (не здавлюватись).

---

## Що тренуємо (Розділ 4 конспекту)

| Властивість | Де застосовуємо |
|---|---|
| `display: flex` | навбар і контейнер карток |
| `justify-content: space-between` | навбар (лого зліва, лінки справа) |
| `justify-content: center` | центрувати сітку карток |
| `align-items: center` | вирівняти елементи навбару по висоті |
| `flex-wrap: wrap` | перенос карток на новий рядок |
| `gap` | відстань між картками |
| `flex: 1 1 280px` | картка: мінімум 280px, може рости |

## Вимоги

### HTML

Структура сторінки:

```html
<body>
  <header class="navbar">
    <span class="logo">MyPortfolio</span>
    <nav class="nav-links">
      <a href="#">Про мене</a>
      <a href="#">Проекти</a>
      <a href="#">Контакти</a>
    </nav>
  </header>

  <main class="cards-grid">
    <!-- три картки .card -->
    <article class="card"> ... </article>
    <article class="card"> ... </article>
    <article class="card"> ... </article>
  </main>
</body>
```

Вміст всередині `.card` — на твій смак (спрощена версія з задачі 01).

### CSS

**Навбар:**
```css
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  /* padding, background — на твій смак */
}

.nav-links {
  display: flex;
  gap: 24px;
  /* прибери стандартне підкреслення у посилань */
}
```

**Сітка карток:**
```css
.cards-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
  justify-content: center;
  /* padding — щоб не злипалось з краями */
}

.card {
  flex: 1 1 280px;
  max-width: 360px;
  /* решта стилів картки — як у задачі 01 */
}
```

## Що НЕ потрібно

- `position: absolute/fixed` — ці вже знаєш, не потрібні тут
- JavaScript
- Медіа-запити — Flexbox сам адаптується через `flex-wrap` + `flex: 1 1 280px`
- Реальні посилання — `href="#"` достатньо

---

### Що зроблено

- Навбар з SVG-лого зліва і навігацією справа (`justify-content: space-between`)
- Сітка з 4 карток з переносом по 3 в рядок (`flex-wrap: wrap`)
- Кнопка "↑" фіксована в правому нижньому куті (`position: fixed`)
- Список навичок у картці переноситься при нестачі місця (`flex-wrap: wrap` на `ul`)

### Додатково

Замість `flex: 1 1 280px` + `max-width: 360px` з умови задачі використано точнішу формулу:

```css
.articles article {
  flex: 0 1 calc((100% - 80px) / 3);
  min-width: 0;
}
```

`(100% - 80px) / 3` — контейнер мінус два `gap` по 40px, ділений на 3. Завжди рівно 3 картки в рядок незалежно від ширини вікна.

---

### Теми які обговорювали

**`flex-grow` і одинока картка в рядку**
- `flex-grow: 1` означає "займи весь вільний простір у рядку"
- Коли 3 картки в рядку — простір ділиться порівну, виглядає добре
- Коли картка одна в рядку — вона отримує весь простір і розтягується на всю ширину

**Два підходи до обмеження ширини картки**
- `max-width: 360px` — картка не росте більше 360px, але ширина залежить від розміру вікна
- `flex: 0 1 calc((100% - 80px) / 3)` — точна формула, завжди рівно 1/3 контейнера після gap

**`min-width: 0` на flex-елементі**
- За замовчуванням flex-елемент не може звужуватись нижче ширини свого контенту (`min-width: auto`)
- `min-width: 0` знімає це обмеження — картка може бути вужчою за свій контент

**Відсотки vs пікселі у `flex-basis`**
- `flex: 1 1 20%` — відсоток від контейнера, веде себе непередбачувано з `gap` в пікселях
- `flex: 1 1 280px` — фіксований мінімум, браузер точно знає скільки карток вміщується

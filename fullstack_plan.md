# Full Stack Developer — Дорожня карта

**Профіль:** початківець, 3–5 год/день, ціль — перша робота джуна
**Орієнтовний час:** 12–14 місяців

---

## Стек

| Рівень | Технології |
|---|---|
| **Frontend** | HTML → CSS → JavaScript → TypeScript → React |
| **Backend** | Node.js → Express → PostgreSQL → Prisma |
| **Інструменти** | Git, VS Code, Docker (базово), Vercel / Railway |

---

## Фаза 1 — Фундамент (місяці 1–3)

**Мета:** впевнено писати HTML, CSS, базовий JavaScript, вміти користуватись Git.

| Тема | Що опанувати |
|---|---|
| **HTML5** | Семантична розмітка, форми, атрибути доступності |
| **CSS3** | Flexbox, Grid, медіа-запити, анімації, змінні |
| **JavaScript** | Типи, функції, масиви, об'єкти, DOM, події, fetch |
| **Git + GitHub** | commit, push, pull, гілки, pull request |

**Результат фази:** робочий landing page + форма зворотного зв'язку, опублікований на GitHub.

---

## Фаза 2 — JavaScript в глибину (місяці 3–5)

**Мета:** зрозуміти мову на рівні, достатньому для React і Node.

| Тема | Що опанувати |
|---|---|
| **ES6+** | `let/const`, arrow functions, деструктуризація, spread, модулі |
| **Асинхронність** | Callbacks → Promises → `async/await` |
| **ООП** | Класи, прототипи, `this` |
| **Алгоритми** | Базові структури даних, сортування, рекурсія |

**Результат фази:** SPA-додаток (наприклад, todo-list або погодний додаток) з API запитами, без фреймворку.

---

## Фаза 3 — Frontend з React (місяці 5–8)

**Мета:** будувати сучасні UI на рівні джуна.

| Тема | Що опанувати |
|---|---|
| **React** | JSX, компоненти, props, state, хуки (`useState`, `useEffect`, `useContext`) |
| **TypeScript** | Типи, інтерфейси, generics — достатньо для React |
| **React Router** | Навігація, вкладені маршрути |
| **Стан додатку** | `useReducer`, Zustand або Redux Toolkit |
| **Стилі** | Tailwind CSS (пріоритет) або CSS Modules |

**Результат фази:** повноцінний React-застосунок з авторизацією (імітованою), маршрутизацією, TypeScript — у портфоліо.

---

## Фаза 4 — Backend (місяці 8–11)

**Мета:** писати REST API, працювати з базою даних.

| Тема | Що опанувати |
|---|---|
| **Node.js** | Event loop, модулі, файлова система |
| **Express.js** | Роутінг, middleware, обробка помилок |
| **PostgreSQL** | SQL запити, JOIN, транзакції |
| **Prisma ORM** | Схема, міграції, CRUD операції |
| **Автентифікація** | JWT, bcrypt, сесії |
| **REST API** | Дизайн ендпоінтів, статус-коди, валідація |

**Результат фази:** повноцінний backend API з базою даних, авторизацією, задокументований.

---

## Фаза 5 — Full Stack інтеграція (місяці 11–13)

**Мета:** зібрати все разом, задеплоїти реальний проект.

| Тема | Що опанувати |
|---|---|
| **Next.js** | SSR, SSG, App Router — об'єднує React + Node |
| **Docker** | Базові контейнери для розробки |
| **Деплой** | Vercel (frontend), Railway (backend + DB) |
| **CI/CD** | GitHub Actions — базовий пайплайн |

**Результат фази:** 2–3 повноцінних full stack проекти в портфоліо, задеплоєних публічно.

---

## Фаза 6 — Пошук роботи (місяць 13–14)

- Оформлення GitHub: README, опис проектів, скріншоти
- CV і LinkedIn для українського / міжнародного ринку
- Підготовка до технічного інтерв'ю (LeetCode — легкий рівень, 30–40 задач)
- Mock-інтерв'ю

---

## Як навчатись ефективно

- **Не читати — робити.** Кожна тема закріплюється практичним завданням
- **Публічний GitHub з першого дня.** Всі проекти — у репозиторіях
- **Застрягнув — 20 хвилин сам, потім питай.** Самостійний пошук рішення — теж навичка
- **Щотижневе повторення.** Переглядай що зробив за тиждень
